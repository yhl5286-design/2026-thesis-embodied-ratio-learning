## 4. 학습자 시나리오 (예: 색상 미션 "1:2 — 쉬움")

1. **감각 모드(기본)** — 빨/파 슬라이더 조작 → 비커 색이 즉시 변하고, 비율에 따라 음높이가 함께 들림. 미션 배지 "쉬움". (관계 힌트는 아직 숨김)
2. **자유 탐색** — 빨/파 양을 바꾸며 같은 색을 두 가지 분량으로 만들면 발견 배너가 뜸. *가법 전략이 감지되면 "더하면 색 변함 / 곱하면 색 그대로" 비교 패널이 동시에 출현.*
3. **reveal 1단계 — "비 보기"** → 비 `1:2`, 관계 힌트 "**파랑이 빨강의 2배**", 그리고 **합성단위 "한 묶음 = 빨1 + 파2 / 이 레시피 = k묶음"** 점도식이 공개.
4. **reveal 2단계 — "더 보기 — 분수·정확한 양"** → 분수(1/2)·나눗셈(0.50)·백분율(50%)·mL이 모두 공개. **기준량을 빨/파로 토글** 가능.

(화음 탭은 동일 흐름: ★ 어울림 → 진동수비 → Hz·분수. 팬플룻은 첫 정확 자르기 시 발견 배너 → 길이·음 공개.)

## 6. 검증·운영 메모

- **검증 방식**: 각 작업 후 로컬 `python -m http.server` + Playwright로 동작 검증(상태·DOM·이벤트). 콘솔 에러는 favicon 404 외 없음.
- **커밋 정책**: 작업당 1커밋, master에 직접(저자 단독 개인 연구 리포). 모든 메시지에 Co-Authored-By 트레일러.
- **호환성**: 기존 4개 토글 (color/sound/harmony/거문고)은 리팩터하지 않고 UX 차원에서 일관(기본 감각모드·표준 토글 컴포넌트 사용)으로 통일 — 회귀 위험 최소화.
- **데이터·로그**: 모든 reveal·blind·bridge swap에 Logger.event 기록 → RQ3 마이크로제네틱 분석 지점.

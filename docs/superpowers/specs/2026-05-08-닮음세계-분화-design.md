# 닮음의 세계 분화 + 명화 2점 추가 — 설계 스펙

- **작성일**: 2026-05-08
- **대상 파일**: `index.html` (단일 HTML 프로토타입)
- **현재 상태**: `🎨 닮음의 세계` 단일 탭에 도형 패턴 5개 + 명화/건축 3개가 혼재

## 1. 목적

학습 대상이 다른 두 그룹(수학 도형 패턴 vs 예술/건축의 비율)을 별도 탭으로 분리하고, 명화 그룹에 르네상스 일점 투시 대표작 2점(아테네 학당, 최후의 만찬)을 추가한다. 학생이 한 탭에서 한 가지 학습 목표에 집중할 수 있게 한다.

## 2. 탭 구조 변경

기존 5개 탭을 6개 탭으로 확장한다. 4번 탭(`닮음의 세계`)이 두 개로 분화된다.

| # | 키 | 라벨 | 변경 |
|---|---|---|---|
| 1 | `color` | 🎨 색상 실험실 | 그대로 |
| 2 | `sound` | 🎵 악기 만들기 | 그대로 |
| 3 | `harmony` | 🎹 화음 감상실 | 그대로 |
| 4 | `similarity` | 📐 도형의 닮음비 | 🆕 (분리) |
| 5 | `masterpiece` | 🖼️ 명화 속 비율 | 🆕 (분리) |
| 6 | `shadow` | 🌟 그림자와 비율 | 그대로 |

순서 원칙: 수학적 기반(도형) → 실세계 응용(명화). `그림자와 비율`은 닮음 응용 학습이라 명화 다음에 둔다.

## 4. 신규 명화 두 점 — 학습 포커스 및 캔버스 사양

두 작품 모두 **일점 투시도법으로 인한 닮음비**를 학습 포커스로 한다. 기존 호쿠사이(나선)·파르테논(황금비)·비트루비안(인체비례)와 차별화되는 학습 포인트다.

### 4.1 🏛️ 아테네 학당 (라파엘로, 1509-1511)

**이미지 소스**: Wikimedia Commons — `Sanzio_01.jpg` (500px 썸네일)

**카드 메타**
- `icon`: 🏛️
- `title`: '아테네 학당'
- `desc`: 르네상스 정점에 라파엘로가 그린 벽화. 그림 양쪽의 벽·아치가 모두 한 점으로 모이는 일점 투시도법으로 그려졌어요. 그 한 점에는 누가 있을까요?
- `reveal`: 소실점 = 플라톤·아리스토텔레스 사이! 양쪽 벽·아치가 모두 한 점으로 수렴해요. 그래서 멀어질수록 인물·기둥이 닮음비로 작아져 보여요. 전경 인물 : 원경 인물 ≈ 2 : 1
- `draw`: `'athens'`

**캔버스 오버레이**
- 빨강 점선 4줄: 좌우 벽·아치에서 시작해 중앙으로 수렴하는 원근선
- 노랑 원: 소실점 (플라톤·아리스토텔레스 사이)
- 파랑 화살표: 전경 인물 키 ↔ 원경 인물 키 비교, "≈ 2 : 1" 텍스트
- 좌상단 작은 라벨: "원근 → 닮음비"
- 하단 검정 박스 흰 글씨: *"라파엘로 아테네 학당 (1511) — 멀어질수록 닮음비로 작아져요"*

### 4.2 🍞 최후의 만찬 (다빈치, 1495-1498)

**이미지 소스**: Wikimedia Commons의 "Last Supper (Leonardo da Vinci)" 표제작 500px 썸네일. 정확한 파일명은 commons.wikimedia.org에서 확인 후 사용 (예: `Última_Cena_-_Da_Vinci_5.jpg` 등 표제 페이지의 메인 이미지).

**카드 메타**
- `icon`: 🍞
- `title`: '최후의 만찬'
- `desc`: 다빈치가 밀라노 수도원 식당 벽에 그린 명작. 천장 격자가 멀어질수록 작아지는데, 그 격자가 닮음비를 그대로 보여줘요. 소실점은 어디일까요?
- `reveal`: 소실점 = 예수의 머리! 천장 격자가 1 : ½ : ⅓ : ¼ 등비수열 닮음비로 줄어들어요. 다빈치는 수학적 거리감을 그림으로 증명했어요 ✨
- `draw`: `'lastsupper'`

**캔버스 오버레이**
- 노랑 격자선: 천장 격자 4단계 (1, ½, ⅓, ¼) 칸마다 분수 라벨
- 빨강 별 마커: 소실점 = 예수 머리
- 파랑 점선: 양쪽 벽·천장이 소실점으로 수렴
- 좌상단 작은 라벨: "천장 격자 = 닮음비"
- 하단 검정 박스 흰 글씨: *"다빈치 최후의 만찬 (1498) — 천장 격자가 1 : ½ : ⅓ : ¼로 줄어요"*

## 5. 코드 변경 범위

`index.html` 한 파일 안에서 다음을 수정한다.

### 5.1 마크업
- **탭 버튼 배열** (현 line 516 영역): `shape` 1개를 `similarity` + `masterpiece` 2개로 교체
- **섹션 컨테이너** (현 line 840~ `<section id="shape">` 영역): `<section id="similarity">` + `<section id="masterpiece">` 2개로 분리. 각각 자체 헤더·그리드 컨테이너를 가짐.

### 5.2 자바스크립트
- **데이터 배열** (현 line 2156~ `SHP_ITEMS`): 두 개로 분할
  - `SIM_ITEMS` — 시에르핀스키, 코흐, 황금비 나선, 정오각형 별, 나무 프랙탈 (5개)
  - `ART_ITEMS` — 파르테논, 비트루비안, 호쿠사이, 아테네 학당, 최후의 만찬 (5개)
- **그리기 디스패치 객체** (현 line 2252 영역): `athens: shpDrawAthens`, `lastsupper: shpDrawLastSupper` 두 키 추가
- **신규 함수**: `shpDrawAthens(ctx, W, H)`, `shpDrawLastSupper(ctx, W, H)` — 기존 `shpLoadImage()` 헬퍼 재사용
- **카드 렌더 함수**: 기존 1개를 두 컨테이너에 각각 호출하도록 인자화 (예: `renderShapeGrid(items, containerId)`)
- **`switchTab()` 핸들러**: `'similarity'`, `'masterpiece'` 케이스 추가, `'shape'` 제거

### 5.3 CSS

- 카드 그리드 CSS, 캔버스 스타일링

## 7. 위험 / 가정

- **이미지 로딩 의존**: Wikimedia 썸네일이 외부 호스트라 네트워크 실패 시 캔버스가 비어 보일 수 있다. 이는 기존 비트루비안·호쿠사이도 같은 한계 → 새 그림에도 동일 정책 적용, 별도 fallback은 도입하지 않는다.
- **저작권**: 두 작품 모두 16세기 작 → 퍼블릭 도메인. Wikimedia Commons에서 자유 사용 가능.
- **이미지 URL 안정성**: Wikimedia 썸네일 URL이 바뀔 위험은 낮지만 0은 아님. 기존 두 명화도 같은 위험을 안고 있어 별도 대비 없음.
- **소실점 좌표 정밀도**: 캔버스에 이미지를 그릴 때 화면 비율이 원본과 어긋날 수 있다. `shpLoadImage`가 dx/dy/dw/dh를 정해주므로 그 좌표계 안에서 비율 위치(예: `dx + dw*0.5`)로 소실점·격자선 좌표를 잡는다.

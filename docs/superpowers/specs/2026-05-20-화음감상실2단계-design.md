# 화음 감상실 2단계 (Spec E) — 설계 스펙

- **작성일**: 2026-05-20
- **대상 파일**: `index.html` (단일 HTML 프로토타입)
- **범위**: `harmony` 탭에 **단계 구조 추가** — 1단계(도 vs 선택음, 현행) + **2단계(서로 다른 두 음 비교, 신규)**. 음정을 **순정률로 전환**.
- **선행**: Spec 1·C·D 병합 완료 — `Logger`, `harm-blind` 토글 패턴 재사용
- **상위 맥락**: [[project_logging_redesign]], reverse scaffolding([[project_design_direction]])

## 1. 목적

기본음 도와 다른 음을 비교하는 현재 활동을 **1단계**로 두고, **미와 솔처럼 서로 다른 두 음끼리** 비교하는 **2단계**를 새로 만든다. 두 음의 주파수 비를 약분해 보여 주고, 단순한 비일수록 잘 어울린다는 비례–협화 관계를 임의의 음 쌍에서도 발견하게 한다. 이를 위해 음정을 **순정률**로 바꿔 임의 쌍의 비가 깔끔하게 나오도록 한다.

## 2. 현재 상태 (출발점)

- `#lab-harmony`: 상단 `harm-blind` 토글 바 + 발견 배너(`harmDiscBanner`/`revealHarmRatios`) + `#harmS2` 컨테이너(피아노 8건반 `#pianoKeys`, 함께/순서 듣기 버튼, 정보 `#pianoInfo`, 파형 `#waveCard`/`waveCanvas`, 핵심 원리 박스).
- `PKEYS`(8): **피타고라스 율** — 도1:1·레9:8·미81:64·파4:3·솔3:2·라27:16·시243:128·도↑2:1. `pianoFreq(i)=C4*p/q`. `pianoSel`(기본 솔). 1단계는 항상 **도(C4) vs PKEYS[pianoSel]** 비교.
- `INTERVALS`·`CONSONANCE` 맵은 피타고라스 비 키 기반. `consonanceOf(rp,rq)`로 별점. `drawWaveAnim`은 **도 고정 + 선택음** 두 파형 + 만남점.
- `harmStage(n)` 함수는 사실상 빈 껍데기(buildPiano+stopWaveAnim). 화음 감상실엔 **로깅이 없음**(Spec 1에서 미적용).

## 4. 순정률 전환

- `PKEYS` 비를 순정률로 교체:
  - 도 1:1, 레 9:8, 미 **5:4**, 파 4:3, 솔 3:2, 라 **5:3**, 시 **15:8**, 도↑ 2:1.
- `INTERVALS` 키 갱신: `'5:4':'장3도'`, `'5:3':'장6도'`, `'15:8':'장7도'`(기존 81:64·27:16·243:128 항목 대체). 1:1·9:8·4:3·3:2·2:1은 유지. (INTERVALS는 음정 *이름* 표시용 — 어울림 별점과 별개.)
- **어울림 평가 통일**: 기존 `CONSONANCE` 맵 + `consonanceOf`를 제거하고, **1·2단계 공통으로 단일 `rateRatio(a,b)`**(§6.3)를 쓴다. 도-상대 1단계도 약분 비(예 도:미=4:5)를 `rateRatio`에 넣어 별점·설명을 얻는다. → 같은 비는 어디서나 같은 별점(모순 제거, DRY).
- 핵심 원리 박스의 예시(도:시=128:243)를 순정률(도:시=8:15)로 갱신.

## 5. 단계 구조 (1단계/2단계)

- `#harmS2` 위에 단계 바 추가:
```
[1단계: 도와 비교]  [2단계: 두 음 비교]
```
`harmStage(1)`/`harmStage(2)`로 토글(기존 함수 재구성). 1단계 컨테이너=현 `#harmS2`(이름 유지 가능), 2단계 컨테이너=신규 `#harmStageTwo`. 단계 전환 시 파형 정지·해당 단계 빌드.
- 단계 전환해도 `harm-blind` 상태·발견 배너는 공유.

## 6. 2단계 — 두 음 비교 (신규)

### 6.1 UI
- **음1 선택줄**(8건반)과 **음2 선택줄**(8건반). 각 줄에서 현재 선택을 강조(`pk-sel` 류). 기본값 예: 음1=미, 음2=솔.
- 버튼: **함께 듣기**(두 음 동시), **순서대로 듣기**(음1→음2).
- 정보 영역: 두 음 이름, (blind 해제 시) 각 음 Hz, **음1:음2 약분 비**, **어울림 별점·설명**.
- 파형 카드: 두 선택음의 파형 + 만남점(일반화된 `drawWaveAnim`).

### 6.2 비 계산
- `freqA=pianoFreq(selA)`, `freqB=pianoFreq(selB)`. 두 음은 `C4*p/q` 꼴이므로 정수비: `a=pA*qB`, `b=pB*qA`, `g=gcd(a,b)` → `a/g : b/g`. 순정률이라 대부분 깔끔(미:솔=5:6, 도:솔=2:3, 미:라=3:4). (레-파 등 일부는 32:27처럼 복잡 — 음악적으로 실제 그러함, 그대로 표시.)

### 6.3 어울림 별점 — 단일 `rateRatio(a,b)` (1·2단계 공통)
- 약분 비 `a:b`의 단순성으로 별점(작을수록 협화). `m=max(a,b)` 기준, 위에서부터 먼저 맞는 규칙 적용:
  - m≤2 → ★5 "완벽한 어울림" (1:1, 1:2)
  - `{2:3,3:2}` → ★5 "아주 잘 어울림" (완전5도)
  - m≤6 → ★4 "잘 어울림" (3:4 완전4도, 4:5 장3도, 5:6 단3도, 3:5·5:3 6도)
  - m≤10 → ★3 "보통" (5:8 단6도, 8:9 장2도 등)
  - m≤16 → ★2 "약한 어울림"
  - 그 외 → ★1 "잘 안 어울림" (8:15 장7도 등)
- 반환: `{stars, level}`. 별 문자열은 `★`×stars + `☆`×(5-stars). 1단계·2단계 모두 동일 비→동일 결과(예: 도:미=4:5, 음1·음2가 도·미여도 → ★4 일치).

### 6.4 파형 일반화
- 현 `drawWaveAnim`이 `f1=C4` 고정 + 선택음을 그림. 두 주파수를 인자/상태로 받아 그리도록 일반화: 1단계는 (C4, pianoFreq(pianoSel)), 2단계는 (freqA, freqB). 만남점 계산·범례(음1/음2)도 일반화.

## 7. blind / reveal
- `harm-blind` 클래스 공유: 비·Hz·별점 수치를 숨기고 "귀로 먼저" 발견 유도. 2단계에서도 강한 협화(★4+)를 들으면 발견 배너 노출(기존 로직 일반화) → reveal 시 수치 표시.
- 토글 → `Logger.event('blind_toggle',{tab:'harmony',blind})`.

## 8. 로깅 (microgenetic)
- 화음 감상실 진입(`switchTab('harmony')`) + 단계에 따라:
  - 1단계 활성 시 `harmony.base` open trial 시작(중복 가드). 선택음 바뀌거나 함께/순서 들을 때 `trialState({base:'도', other:이름, ratio, stars})`.
  - 2단계 활성 시 `harmony.compare2` open trial. 음1/음2 바꾸거나 들을 때 `trialState({a:이름, b:이름, ratio, stars})`.
- 단계 전환·탭 이탈 시 해당 trial `endTrial(open)`.
- blind_toggle 이벤트. (Logger 동기·safe.)

## 9. 데이터 구조 영향
- 새 `activityId`: `harmony.base`, `harmony.compare2`. `taskId`: `base`, `compare`. events 신규 값 없음. 시트 스키마 그대로.

## 10. 검증 방침

- 핵심 체크: (a) 순정률 1단계 비 표시(미 5:4 등)·별점 일관, (b) 단계 바 전환, (c) 2단계 음1·음2 선택→약분 비(미:솔=5:6, 도:솔=2:3)·별점·파형, (d) blind 기본 숨김·reveal, (e) 1·2단계 open trial 로깅(trajectory), (f) 콘솔 에러 0·다른 탭 회귀 없음.

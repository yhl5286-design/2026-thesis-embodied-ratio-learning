# 악기 제작실 (Spec D) — 설계 스펙

- **작성일**: 2026-05-20
- **대상 파일**: `index.html` (단일 HTML 프로토타입)
- **범위**: `instrument` 탭(악기 제작실)의 **거문고 재설계**(안족=괘 누름·햅틱·비 토글) + **팬플룻 사운드 개선**(피리 음색)
- **선행**: Spec 1(로깅 인프라)·Spec C 병합 완료 — `Logger`, blind 토글 패턴 재사용
- **상위 맥락**: [[project_logging_redesign]], reverse scaffolding([[project_design_direction]])

## 1. 목적

악기 제작실의 거문고를 **괘(프렛)를 눌러 연주하는** 방식으로 바꿔 "누르는 감각"을 살리고, 팬플룻 음색을 **피리풍으로 음정 정확·예쁘게** 개선한다. 현 길이는 기본 숨기되 **토글로 비(ratio)를 정량화**해 색상·화음의 2:3과 이어지는 전이(breadth) 단서를 제공한다.

## 2. 현재 상태 (출발점)

- `instrument` 탭에 팬플룻(`inst-panflute`)과 거문고(`inst-string`)가 있음. `initInst()`가 둘 다 초기화.
- **거문고**: `strCanvas`(640×200)에 몸체+현 1개. **안족(빨강 삼각형)을 자유 드래그**해 현 길이(`strLenA`)를 바꾸면 음높이가 변함(`strFreqFromLen(l)=STR_REF/l`, `STR_REF=60*262`, `STR_MIN=28`,`STR_MAX=68`). 현재 **"현 길이: X cm" 숫자가 노출**됨. 바닥에 음 위치 눈금(`XYLO_FREQS`). 드래그 핸들러는 `strInitCanvas`.
- **팬플룻**: 갈대 관을 잘라 도레미파솔라시 7음을 만드는 제작 과제(유지). 사운드는 `pfNote(ctx,freq,t,gain)` — 사인+2배음+5Hz 비브라토+밴드패스 입김 노이즈(플룻풍).

## 3. 결정 사항 (합의됨)

| 항목 | 결정 |
|---|---|
| 거문고 조작 | **괘(프렛) 눌러 집기 — 이산 위치** (자유 드래그 제거) |
| 음 구성 | **전통 5음(오음계) 도·레·미·솔·라** |
| 활동 목표 | **자유 연주** (목표 곡 없음) |
| 누름 피드백 | 시각(눌림 애니메이션+현 진동) + **태블릿 햅틱 `navigator.vibrate(25)`** (지원 기기만) |
| 현 길이 표시 | 기본 **숨김**, **비율 보기 토글**로 길이+비 정량화 노출 |
| 팬플룻 | **사운드만 피리풍으로 개선**(음정 정확·예쁘게), 제작 과제 로직은 유지 |
| 로깅 | 거문고 = `geomungo.play` open trial(누른 음 시퀀스), blind_toggle 이벤트 |

## 4. 거문고 재설계

### 4.1 괘(프렛) 구성 — 오음계 5음
- 음: 도·레·미·솔·라. 기준 도 = 262Hz(현 길이 60cm). 각 음의 현 길이는 `len=STR_REF/freq`로 계산(주파수 역비례).
- 주파수(순정/평율 근사, 기존 `XYLO_FREQS` 활용): 도 262, 레 294, 미 330, 솔 392, 라 440 Hz.
- 길이(cm): 도 60.0, 레 53.5, 미 47.6, 솔 40.1, 라 35.7 (= `STR_REF/freq`).
- 5개 괘를 현 위의 해당 길이 위치에 **또렷한 누름 가능 표식**으로 그린다(라벨 도·레·미·솔·라).

### 4.2 누름 인터랙션 ("누르는 느낌")
- 괘를 **탭(클릭/터치)** 하면:
  1. `strLenA`를 그 괘의 길이로 설정 → 안족(누름 표식)이 그 위치로 이동, 현 울리는 구간이 그 길이로 갱신(캔버스 재draw).
  2. 해당 음 재생(`stringNote(ctx, freq, ...)`).
  3. **현 진동 시각 효과**: 울리는 구간을 짧게 흔드는 애니메이션(예: 사인파 형태로 2~3회 진동 후 정지, requestAnimationFrame 300~400ms).
  4. **눌림 피드백**: 괘 표식이 살짝 들어가는 애니메이션(스케일/오프셋).
  5. **햅틱**: `if(navigator.vibrate)navigator.vibrate(25);` — 미지원 기기에선 자동 무시(앱 정상). progressive enhancement.
- 자유 드래그(`strInitCanvas`의 pointer 드래그)는 **제거**하고, 괘 영역 탭 히트테스트로 대체. 안족은 "현재 누른 위치" 표식으로 유지.

### 4.3 현 길이/비 — 기본 숨김 + 비율 보기 토글
- 기본 상태: 현 길이 cm 숨김(지시 "길이만 보이지 않고"). 캔버스의 "현 길이: Xcm" 텍스트 비표시.
- **비율 보기 토글**(거문고 영역 우상단, 색상·화음·소리의 `*-mode-toggle` 패턴): 켜면
  - 각 괘 음의 **현 길이(cm)** 표시
  - **도 대비 비** 표시: 누른 음의 울리는 길이 : 도의 길이를 기약비로. 예) 솔 누름 → "솔 길이 : 도 길이 = 40 : 60 = **2 : 3**" (색상·화음의 2:3과 동일 — 전이 단서). 도:미=4:5, 도:라=3:5도 동일 방식.
  - 절반 길이=옥타브(2:1)는 오음계엔 도↑가 없어 직접 안 나오지만, 길이↔음높이가 역비례임을 길이 비로 보여줌.
- 토글 상태 변화는 `Logger.event('blind_toggle',{tab:'instrument',inst:'geomungo',blind})`.

### 4.4 비례 학습 위치
- 거문고는 자유 연주·감각 중심이되, **비 토글**로 길이 비를 발견할 수 있게 함(reverse scaffolding: 누르고 들은 뒤 비 노출). 정량 심화는 화음 감상실 담당. 괘 위치 자체가 길이 비로 배치돼 시각 단서 상존.

## 5. 팬플룻 사운드 개선 (피리 음색)

### 5.1 목표
- **피리풍 음색**: 겹서 리드 특유의 풍부한 배음·약간의 리드감(부드러운 플룻보다 또렷). 단 거칠지 않고 **예쁘게**.
- **음정 정확**: 합성 기본음은 목표 주파수 정확(`pfFreqFromLen`/`XYLO_FREQS` 기반, 현행대로). 음색 변경이 음정에 영향 주지 않도록 기본음 주파수 유지.

### 5.2 구현 방향 (`pfNote` 재설계)
- 기본음 + **홀수·짝수 배음 혼합**(예: 2·3·4배음을 리드감 있게 비중 조정)으로 피리쪽 음색. 톱니/구형파를 약하게 섞되 저역 필터로 부드럽게.
- 부드러운 어택(40~80ms) + 자연스러운 릴리스 + **완만한 비브라토(5~6Hz, 깊이 작게)** 로 "예쁜" 톤.
- 입김 노이즈는 약하게 유지(피리도 숨소리 있음) 또는 더 줄여 또렷하게.
- 살짝의 따뜻함을 위해 마스터에 약한 로우패스/약한 리버브(선택). 과하지 않게.
- **주관적 튜닝 필요**: 음색은 청취로 다듬는다 — 구현 후 브라우저에서 실제로 들어보고 1회 리파인(밸런스·비브라토·필터). "예쁘다"의 최종 판단은 사용자 확인.
- `pfNote` 시그니처(`ctx,freq,t,gain`)·호출부(`pfPlaySel`/`pfPlayAll`/제작 과제)는 변경 없음 — 음색 내부만 교체.

## 6. 로깅 (microgenetic)

`Logger`(Spec 1) 재사용, 동기·safe.
- 거문고 화면 진입(`instSet('string')` 또는 instrument 탭에서 거문고 활성) 시 `gl`/별도 상태에 `geomungoTrial = Logger.startTrial({tab:'instrument',activity:'geomungo.play',task:'play'})` 시작(중복 시작 가드).
- 괘 누를 때마다 `Logger.trialState(geomungoTrial,{note, lenCm:strLenA, ratioToDo:'2:3' 등})`.
- 팬플룻 전환·탭 이탈 시 `Logger.endTrial(geomungoTrial,{outcome:'open',finalState:{...}})`.
- 비율 보기 토글 → `Logger.event('blind_toggle',{tab:'instrument',inst:'geomungo',blind})`.
- (팬플룻 제작 과제 로깅은 이번 범위 밖 — 사운드만 손댐. 필요 시 후속.)

## 7. 데이터 구조 영향
- 새 `activityId`: `geomungo.play`. 새 `taskId`: `play`. events 신규 값 없음(blind_toggle 기존). trials/events 시트 스키마 그대로.

## 8. 검증 방침
- 무프레임워크·단일 HTML → 인라인 스크립트 `node --check` + Playwright 브라우저 검증.
- 핵심 체크: (a) 거문고 5개 괘 표시·탭하면 안족 이동+음 재생+진동 시각효과, (b) 햅틱은 지원 기기에서만(미지원 무시·에러 0), (c) 길이 cm 기본 숨김·비율 토글로 길이+비(솔→2:3) 노출, (d) `geomungo.play` open trial에 누른 음 trajectory 적재, (e) 팬플룻 사운드 재생 정상·음정 정확(주관적 음색은 청음), (f) 자유 드래그 제거 후 잔존 핸들러·에러 0, (g) 다른 탭/팬플룻 회귀 없음.
- 햅틱은 데스크톱/iPad에서 미지원이라 Playwright로는 호출 시도만 확인(에러 없음). 실제 진동은 안드로이드 태블릿 실기 확인 필요(사용자).

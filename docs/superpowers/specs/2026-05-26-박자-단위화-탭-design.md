# 박자 탭 · 단위화 탭 (Spec F) — 설계 스펙

- **작성일**: 2026-05-26
- **대상 파일**: `index.html` (단일 HTML 프로토타입)
- **범위**: 두 개의 신규 탭 추가 — **단위화 탭**(`unit`), **박자 탭**(`beat`)
- **선행**:
  - Spec 1(로깅 인프라) 병합 완료 — `Logger.startTrial/trialState/endTrial/event` 재사용
  - W4(표현 교량 `ratioBridgeBlock`) 구현 완료 — 비/분수/나눗셈/% 자동 표시
  - W5("~마다" 합성단위 점도식 `renderCompositeUnit`) 구현 완료 — 토글로 재사용
- **상위 맥락**: [[project_v2_implementation]], [[project_design_principles_synthesis]], [[project_logging_redesign]]

## 1. 목적

두 신규 탭은 RatioSense의 **시간 차원 비례 학습**을 발달 계열에 맞춰 보완한다.

- **단위화 탭**: 한 마디(고정 시간) 안에서 음표 단위(♩/♪/♬/3연음 등)로 채우기 → 단위 ↑ / 개수 ↓ 역관계와 합성단위(composed unit, Tzur 2021) 음악적 체화.
- **박자 탭**: 두 패턴이 동시 진행되는 폴리리듬에서 "같이 치는 순간"을 청각으로 발견 → Lovemore(2025)의 박수선(비)·시간선(측도) 분리 통찰을 디지털로 매개.

두 탭은 **시간 측도의 두 양상**(내적 합성단위 / 외적 비)을 분리해 다루며, 발달 계열 **색상(연속 측도) → 단위화(시간 합성단위) → 박자(시간 두 패턴 비) → 화음(시간 연속 측도)**을 완성한다.

## 2. 이론적 근거

| 출처 | 흡수 지점 |
|---|---|
| Lovemore (2025) | 박수선=비, 시간선=측도, 두 표상 분리 → 두 탭 Stage 2 공통 |
| Lovemore (2025) | 0≠1 갈등(첫 박을 0에 둘지 1박째에 둘지) → 갈등 제거 대신 학습 자료로 노출(토글) |
| Bamberger | "coming out even" 미적 해소 → Stage 1 발견 트리거 |
| Bamberger · diSessa | transformations & invariants (변환과 불변량) → Stage 3 통합 |
| Tzur (2021) | composed unit · iteration · multiplicative reasoning → 단위화 탭 전체 |
| Abrahamson · Shvarts | 신체 협응 기반 attentional anchor → 박자 Stage 1 손박수, 단위화 Stage 1 |
| Tourniaire & Pulos (1985) | 연속량 → 이산량 발달 계열 → 탭바 배치 |
| DJ Baby Mix (dj-babymix.com) | 다중 트랙 layer + 공유 BPM → 박자 Stage 2 합주 구조 |

**의도적 폐기**: 한국 장단 차별화 모듈(세마치·중모리·자진모리), 강건너기 신체 비유 — 사용자 결정으로 단순화. 분모는 기본 박 범위(2·3·4·6·8·16)만 다룸.

## 3. 결정 사항 (합의됨)

| 항목 | 결정 |
|---|---|
| 두 탭 결합도 | 비율 공유만 (앱 코드 독립). 명시적 다리 버튼 없음. |
| 학습 매체 | 음악 통일 (Web Audio). 신체 비유·시각 비유 사용 안 함. |
| 단위화 매체 | 음표 단위로 한 마디 채우기 (♩/♪/♬/3연음, note value) |
| 박자 매체 | DJ Baby Mix 스타일 다중 트랙 layer (5종 악기, 같은 BPM 공유). Stage 1 손박수 진입 |
| 분모 범위 | 단위화: 2·4·8·16·3(음표 가치) / 박자: 트랙별 1~6박/마디 (LCM 만남 자동 계산) |
| 마디 기본 길이 | 두 탭 공통 2.4초 (100 BPM × 4박 기준). Stage 3 빠르기 변환에서 1.2~4.0초 가변 |
| Stage 0 신체 활동 | **없음** — 앱 단독 완결 (디지털 매개에 집중) |
| 발견 트리거 | 학습자 주도 버튼 (단위화: 💡 "발견했어!" / 박자: ⚡ "같이 친다!") |
| 단계적 reveal | 정성 → 카운트 → 비 → 분수 → 위치(시간선) |
| 0≠1 갈등 | 토글로 노출, 양쪽 다 시도 가능 |
| W4 교량 연결 | Stage 2 reveal 후 자동 표시 (`ratioBridgeBlock` 재사용) |
| W5 점도식 | 단위화 Stage 1에 토글로 재사용 (`renderCompositeUnit`) |

## 4. 탭바 배치

```
🎨 색상 → 📐 단위화 (신규) → 🎵 소리 → 🎹 악기 → 🥁 박자 (신규) → 🎼 화음 → 🌟 그림자
```

배치 원리: 색상(연속 측도)은 진입, 단위화는 시간 매체 진입점이라 소리·악기 앞, 박자는 화음 직전(폴리리듬 → 화음 비). 그림자는 기존 위치 유지.

`switchTab()`에 `unit`·`beat` 분기 추가. `ALL_TABS` 배열 확장.

## 5. 단위화 탭 (`unit`)

한 마디(고정 시간, 기본 2.4초)를 학습자가 고른 **음표 단위**로 반복 재생.

### 5.1 Stage 1 — 단위 채우기

#### UI / 동작
- **단위 카드 5개**: 𝅗𝅥(반음표) / ♩(4분) / ♪(8분) / ♬(16분) / 3연음 (3·tuplet). 가로 한 줄.
- **한 마디 막대**: 선택된 단위로 한 마디를 채워 자동 반복 재생. 진행 커서가 좌→우 이동.
- **음원**: 마림바·우드블록 톤(둔하지 않고 박이 또렷한 신스). 음 높이는 단위마다 살짝 다르게(♩=C5, ♪=D5 등)해 단위 차이를 음색으로도 구분.
- **비교 줄**: 직전에 시도한 단위와 지금 단위를 같은 마디 위에 병치(점선 분할 표시). 두 줄 상하 배치.
- **blind 모드 기본 ON**: 개수·1/n 분수 모두 숨김. 음표 글자만 보임.

#### 발견 트리거
- "💡 발견했어!" 버튼.
- 자동 힌트: 단위 카드를 **3종 이상 시도** + **90초 경과** 시 살짝 깜빡임 (조작 단념 방지). 박자 탭과 시간 통일.

#### 단계적 reveal
1. 발견 트리거 누르면 1단계: 개수 숫자 등장 (𝅗𝅥=2, ♩=4, ♪=8, ♬=16, 3연음=3).
2. 학습자가 "그래서 단위가 작아지면 개수는?" 질문 카드 클릭 → 2단계: 역관계 텍스트("단위 ½배 → 개수 2배").
3. W5 점도식 토글: 한 마디 = k묶음 시각화 (단위화 활동에 맞게 색·라벨 조정).

#### 로그
- `Logger.startTrial({tab:'unit', activity:'unit.fill', task:'explore'})`
- `trialState`: `{currentUnit, prevUnit, attemptsByUnit:{half:0,quarter:0,eighth:0,sixteenth:0,triplet:0}, tempo}`
- `endTrial outcome`: `'found'` | `'open'`. `finalState`: `{unitsTried:[...], lastUnit, discoveryAt}`.
- `events`: `unit_select(unit)`, `discovery_trigger`, `inverse_relation_view`, `composite_unit_toggle`.

### 5.2 Stage 2 — 음표선 ↔ 시간선

발견 후 자동 reveal. Stage 1 화면 하단에 새 패널 등장.

#### UI / 동작
- **음표선 (위)** = 비: 선택 단위가 한 마디에 *몇 개* 들어가는지 카운트 점/음표만 표시. 시간 없음. "♩ ♩ ♩ ♩" 형태. 클릭하면 그 박만 들림.
- **시간선 (아래)** = 측도: 0~1 자에 단위 위치 표시 (♩이면 0, 1/4, 1/2, 3/4). 분수 라벨 같이 노출.
- **0≠1 토글**: "🅰 0박째부터 / 🅱 1박째부터" 두 버튼. 첫 음표 위치만 바뀌고 분할 그대로.
- **핵심 질문**: "두 줄은 같은 걸 말하나, 다른 걸 말하나?" — 객관식 답(같은 것/다른 것/잘 모르겠어).
- **W4 교량 자동 연결**: 화면 하단에 `ratioBridgeBlock` 호출 → "♩ = 한 마디의 1/4", 분수·나눗셈·% 표시.

#### 로그
- `activity:'unit.twoline'`, `task` = 현재 단위.
- `events`: `zero_one_toggle(mode)`, `twoline_question_answer(answer)`, `note_click(position)`.

### 5.3 Stage 3 — 변환·불변량

Stage 2 다음. 학습자가 자유 변형하며 무엇이 보존되는지 발견.

#### UI / 동작
- **3 변환 도구**:
  - ① **빠르기 바꾸기**: 한 마디 길이만 1.2~4.0초 사이 변경. 단위·개수 그대로.
  - ② **단위 바꾸기**: ♩ ↔ ♪ ↔ ♬ 토글. 개수 자동 변환, 비 자체가 변함.
  - ③ **분해 (등가)**: 한 음표를 두 개로 쪼개기 (♩ → ♪♪). 같은 마디·같은 길이·다른 표기.
- **이전 vs 지금 비교 줄**: 변환 전후 두 줄 병치 (Stage 2 시간선 형식).
- **체크리스트**: "변한 것" / "그대로인 것" 항목 (박 간격·개수·마디 길이·단위 크기·비례 분할). 학습자 다중 선택.

#### 로그
- `activity:'unit.transform'`, `task` = 시작 단위.
- `events`: `transform_apply({type, before, after})`, `invariance_check({changed:[...], invariant:[...]})`.

## 6. 박자 탭 (`beat`) — 재설계 (2026-05-27)

DJ Baby Mix 스타일 다중 트랙 layer 구조. 모든 트랙이 같은 BPM·같은 마디에 자동 동기되어, 학습자가 *새 박자를 자유 창작*하는 과정에서 *같은 박자(=같은 비)*가 자연스럽게 발현. 진입 곡선: 손박수 → 합주 → DJ mix.

### 6.1 Stage 1 — 손박수 🖐 (Hand Clap)

학습 진입점. 한 박을 몸으로 먼저 느끼기.

#### UI / 동작
- 단일 자동 메트로놈 1개 (기본 4박/마디, BPM 100 = 2.4초/마디).
- 큰 "🖐 박수" 버튼. 학습자가 박에 맞춰 누름.
- 박이 떨어질 때 동그라미가 깜빡임 + 클릭음. 학습자 박수도 별도 색으로 동시 표시.
- 정확도 판정: 박과 박수 시각 차이 ±200ms 이내 → 🎯 정확 표시.
- 박 수 선택 카드(2/3/4박/마디) — 학습자 임의 변경.
- blind 기본 ON: BPM·박 수 숫자 숨김.

#### 해제 조건
- 한 마디 안 정확 박수 3회 이상 누적 → Stage 2 잠금 해제. 동시에 발견 트리거 자동 발화(짧은 축하 + Stage 2 패널 등장).

#### 로그
- `activity:'beat.clap'`, `task` = `'beats_'+N`.
- `trialState`: `{beats, bpm, claps:[{atMs, beatIdx, accurate:bool}]}`.
- `endTrial outcome`: `'unlocked'` | `'open'`. `finalState`: `{totalClaps, accurateClaps, beats}`.
- `events`: `clap`, `clap_accurate`, `beats_change(n)`, `stage1_unlock`.

### 6.2 Stage 2 — 리듬 합주 🥁🎵 (Layer Mix)

학습자가 새 박자를 만든다. DJ Baby Mix 스타일 다중 트랙.

#### UI / 동작
- **트랙 카드 시스템**: 좌측 카드 팔레트(베이스 🥁 · 드럼 🪘 · 멜로디 🎵 · 손뼉 👏 · 효과 ✨ 5종). 클릭 시 트랙으로 추가 (최대 5트랙).
- **트랙별 박 수**: 각 트랙 카드 안에 박 수 선택(1~6박/마디). 별도 음색.
- **공유 마디**: 모든 트랙은 같은 BPM·같은 마디 길이 공유 → 자동 동기.
- **합주 진행 막대**: 한 마디(반복) 안에 모든 트랙 박 점을 색별 layer로 표시.
- **만남 ⚡**: 두 트랙 이상의 박이 동시에 떨어지는 순간(마디 시작/끝은 항상 만남). 시각 깜빡임 + 공명음.
- **트랙 on/off** 토글 + 볼륨 슬라이더.
- blind 기본 ON. 발견 후 reveal.

#### 발견 트리거
- "⚡ 같이 친다!" 버튼.
- 자동 힌트: 2종 이상 트랙 + 60초 경과 → 살짝 깜빡임.

#### 단계적 reveal
1. 발견 → 트랙 박 수 숫자 + "트랙 N개가 함께 가는 마디" 카운트.
2. 두 트랙씩 짝지어 만남 주기(LCM 기반) 표시. 예: 2박+3박 → "6박마다 만남".
3. W4 교량 자동 연결: 짝지은 두 트랙 비를 `ratioBridgeBlock`으로 비/분수/나눗셈/%.

#### 로그
- `activity:'beat.layer'`, `task` = 트랙 박 수 조합 (예: `'2-3-4'`).
- `trialState`: `{tracks:[{instr, beats, on, vol}], tempo}`.
- `endTrial outcome`: `'found'` | `'open'`. `finalState`: `{tracks, ratios:[[a,b],...], discoveryAt}`.
- `events`: `track_add(instr)`, `track_remove(instr)`, `track_beats_change(instr, n)`, `track_toggle(instr, on)`, `discovery_trigger`, `meet_resonance`.

### 6.3 Stage 3 — DJ Mix 🎛 (변형·불변량)

만든 합주를 자유 변형. "변형해도 같은 박자(비례 분할) 유지하는가" 발견.

#### UI / 동작
- 합주 트랙 상태 유지.
- 변환 도구 3종:
  - ① **BPM 슬라이더** 60~160. 모든 트랙 동시 빠르기 변경 → 박 간격만 변함, 비 유지.
  - ② **트랙 박 수 변경**: 각 트랙 +/− → 비 자체 변경, 만남 주기 변함.
  - ③ **등가 배수**: 전체 트랙 박 수에 ×2 ×3 ÷2 (정수일 때만) — 같은 비 다른 표기, 만남 패턴 동일.
- **이전 vs 지금 비교 줄**: 변환 전후 두 합주 시간선 병치.
- **체크리스트**: "변한 것" / "그대로인 것" (BPM·간격·트랙 수·박 수·만남 주기·비례 분할 등).

#### 로그
- `activity:'beat.dj'`, `task` = 시작 트랙 조합.
- `events`: `transform_apply({type, before, after})`, `invariance_check({changed, invariant})`.

## 9. 별도 관찰·후속

- **두드리기 박 추출 관대도**(±25%) — 실데이터로 튜닝 필요. 부진 학생 대상 시 ±40%까지 완화 검토.
- **음표 단위 음원** — 신스 vs 샘플 결정: Phase 1은 OscillatorNode 신스(짧은 어택+감쇠 envelope), Phase 2에 마림바 샘플 검토.
- **3연음(3-tuplet) 위치 명세** — 한 마디를 3등분하는 단위(0, 1/3, 2/3 위치). 음표 가치 2의 거듭제곱 계열(𝅗𝅥·♩·♪·♬)과 *다른 계열*이므로 시각·음색 단서로 구분 표기. Stage 1부터 노출하되 자동 힌트는 ♩·♪ 비교가 먼저 일어나도록 단위 카드 정렬 좌→우: 𝅗𝅥 → ♩ → ♪ → ♬ → 3연음.
- **모바일 반응성** — 두드림 버튼 큰 hit area(최소 64×64px), 햅틱(`navigator.vibrate`) 활성. 소리 탭 슬라이더 모바일 미해결 이슈([[project_logging_redesign]])는 본 spec 범위 밖.
- **로그 sheet 컬럼** — Apps Script `events`·`trials` 시트에 신규 eventType들 그대로 들어감(스키마 변경 없음). roster·sessions 무영향.
- **앱 절대 비정지** — 메트로놈 스케줄러는 try/catch silent로 감싸 timing 오류가 UI 멈추지 않게.

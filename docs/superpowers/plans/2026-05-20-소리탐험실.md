# 소리 탐험실 (Spec C) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `sound` 탭(소리 탐험실)을 순차 2단계로 바꾼다 — ① 물양↔소리 감각(mL 숨김) → ② 8음 도레미파솔라시도 셀 튜닝 만들기 — 그리고 per-note microgenetic 로깅을 붙이고 죽은 8음 코드를 정리한다.

function glDoremiUpdateDisplay(i){
  const n=gl.doremi[i];
  for(let j=0;j<GL_MAX_CELLS;j++){
    const cell=$('glDRCell'+i+'_'+j);
    if(cell)cell.classList.toggle('filled',(GL_MAX_CELLS-1-j)<n);

  const pct=$('glDRP'+i);if(pct)pct.textContent=n+'칸';
  const target=SCALE_CELLS[i];
  const tuned=(n===target);
  $('glDR'+i).classList.toggle('tuned-unit',tuned);
  const tag=$('glDRT'+i);
  if(tag){
    if(tuned){tag.textContent='✓ '+SCALE_NOTES[i]+'!';tag.className='gl-tune-tag ok';}
    else if(n===0){tag.textContent='눌러서 채워요';tag.className='gl-tune-tag';}

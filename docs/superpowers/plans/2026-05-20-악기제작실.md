# 악기 제작실 (Spec D) 구현 계획 — 거문고 개정

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 거문고를 안족 드래그로 **길이에 따라 음높이가 연속 변화**하게 하고, 모바일 터치를 위해 안족 잡는 영역을 키우며, 잡을 때 햅틱 진동·현 진동 시각효과를 더하고, 현 길이는 기본 숨김+**비율 보기 토글**(솔≈2:3)로 노출한다. 팬플룻은 변경 없음.

**Architecture:** 단일 `index.html` 인라인 JS. 거문고는 이미 `strFreqFromLen`으로 길이→음높이 연속. 변경은 (1) 캔버스 그리기(`strDrawCanvas`)에서 안족 확대·길이텍스트 제거·진동 위상 반영, (2) 입력(`strInitCanvas`) 히트영역 확대+햅틱, (3) 현 진동 애니메이션, (4) 길이/비 DOM 리드아웃+토글, (5) `geomungo.play` 로깅. Spec 1 `Logger` 재사용(동기·safe).

**Tech Stack:** Vanilla JS, Canvas 2D, Web Audio(기존 `stringNote`), `navigator.vibrate`(progressive enhancement), node `node --check`, Playwright.

**검증 방침:** 인라인 스크립트 `node --check` per task + 마지막 Playwright 검증. 햅틱 실진동은 안드로이드 태블릿 실기(사용자), Playwright는 호출 무에러까지.
